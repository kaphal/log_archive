# log_archive

Easy universal bash script that makes copy of logs of system

* [**Project link**](https://github.com/kaphal/log_archive)
* [**original idea**](https://roadmap.sh/projects/log-archive-tool)
* [**Link to MANUAL**](https://github.com/kaphal/log_archive/blob/main/MANUAL.md)

## Compatibility

Script was made for debian-based distros, if you are using different distro and it gives an error, check which shell your distro is using with:
```bash
echo $0
```
